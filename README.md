# Hot's Aerostuff x CBC Armor
1. Скопируйте в libs/ jar-файлы createbigcannons, hotstuff, create (из своей папки mods).
2. JDK 21, затем: ./gradlew build  (нужен Gradle wrapper из MDK NeoForge 1.21.1, либо `gradle build`).
3. Готовый мод: build/libs/hotstuff-cbc-armor-1.0.0.jar -> в папку mods.
Значения брони меняются в src/main/resources/data/hotstuff/block_armor/*.json.
